# Security and scope

- This repository contains detection and investigation content for defensive analysis.
- Execute attack emulation only in an isolated lab with explicit authorization and snapshots.
- Never use this repository to run tests against systems you do not own or administer with permission.
- Treat command lines, usernames, hostnames, IPs, and raw logs as potentially sensitive.
- No production telemetry or credentials should be committed to this public repository.
- Response actions (disable accounts, isolate hosts, block destinations) require authorized incident-response decision-making.
